MFM LUXURY TRAVEL — CLEAN STATIC DEMO

Files
- index.html      Page structure and content
- styles.css      Single production stylesheet
- script.js       Interactions and data
- assets/         Images, ornaments, favicon, lookbook pages and PDF

Maintenance rules
- Keep production CSS in styles.css. Do not create version-layer stylesheets.
- Keep production JavaScript in script.js unless the site is intentionally modularized later.
- Use stable asset filenames and relative paths.
- Remove abandoned selectors, assets and experiments instead of stacking overrides.
- Preserve responsive QA at 360, 390, 430, 458, 768, 1024 and 1440 px when changing layout.

Static-hosting note
The access screen is a client-side privacy gate for a portfolio demo. It discourages casual access but is not server-side authentication.
